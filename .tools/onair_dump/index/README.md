# Semantic Index Scaffold

This folder contains the first normalized semantic index scaffold for `.tools/onair_dump/`.

In this repo, a normalized semantic index is a deterministic JSON artifact that consolidates raw dump sources into stable, diffable semantic collections (leagues, entities, measures, qualifiers, filters, and profiles) with a transparent source inventory.

Expected future consumers:
- semantic-layer tooling
- Plan Engine inspection
- React SPA Source View

Current output file:
- `semantic_index.json`

Current schema file:
- `semantic_index.schema.json`
